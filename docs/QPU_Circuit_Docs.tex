\section{Choose the guide you need}

The documentation is split so a new user does not need to read a large
reference manual from beginning to end.

\subsection{New to programming or the website}

\textbf{\href{QPU_Getting_Started.pdf}{Open QPU Getting Started}}

Begin here to learn what source text, instructions, arguments, compilation,
wires, tokens, and gates mean. It gives an exact website workflow and complete
protocols that can be copied into the editor.

\subsection{New to classical or quantum theory}

\textbf{\href{QPU_Theory_Guide.pdf}{Open Classical and Quantum Theory for QPU}}

This guide starts with bits, Boolean algebra, and truth tables, then develops
complex numbers, Euler's formula, qubits, the Bloch sphere, tensor products,
entanglement, interference, measurement, and the mathematics of every gate.

\subsection{Looking up exact syntax}

\textbf{\href{QPU_Language_Reference.pdf}{Open QPU Language Reference}}

Use this guide for token and constant forms, flags, gate arity, every supported
instruction, child-process binding, truth-table file syntax, compatibility
behavior, errors, grammar, and the glossary.

\subsection{Learning through examples or fixing an error}

\textbf{\href{QPU_Examples_and_Troubleshooting.pdf}{Open QPU Examples and Troubleshooting}}

This guide explains a first circuit, reversible half-adder, interference
experiment, child-process example, common protocol errors, diagnostic codes,
and when to open the Correction Lab.

\section{Recommended learning path}

Getting Started explains each step in detail, with a starter circuit and a
checkpoint question. The starter-circuit cards in the Circuit builder are
numbered with the same steps.

\begin{center}
\begin{tabularx}{\textwidth}{>{\bfseries}p{0.24\textwidth}X>{\raggedright\arraybackslash}p{0.3\textwidth}}
\toprule
Step & What you learn & Where to read\\
\midrule
1. Single qubit & X, H, Z, and measurement; superposition versus
interference. & Getting Started; Theory Guide (single-qubit gates)\\
2. Controlled gates & CNOT, CZ, CY, SWAP: which wire is read and which is
changed. & Theory Guide (controlled gates)\\
3. Reversible logic & CCNOT and AND/OR/XOR/NAND: inputs are kept, answers go
into a target. & Getting Started (half-adder); Theory Guide (derived gates)\\
4. Entanglement & Bell states and phase kickback. & Theory Guide (multiple
qubits); Examples (phase kickback)\\
5. Arithmetic & Full adders, multi-bit adders, comparators, parity. &
Examples (advanced worked circuits)\\
6. Multi-stage & Child processes, uncomputation, oracles, custom gates,
bounded recursion (REC/TREC), and IF/ELSE feed-forward after a measurement. &
Language Reference (process composition); Examples (custom gates)\\
\bottomrule
\end{tabularx}
\end{center}

Throughout, keep the Language Reference open while authoring a protocol, and
use Protocol checks and the Correction Lab when compilation or truth-table
tests report a problem.

\section{Find the explanation for what is on screen}

\begin{itemize}
  \item \textbf{A button or selector:} Getting Started, \emph{Every control on
  screen, by its exact name}.
  \item \textbf{A gate:} select it in the workbench and open \emph{Read the
  full gate reference}, or see the Theory Guide gate chapters.
  \item \textbf{A teal D$n$ badge, a REC box, or yellow IF/ELSE lines:}
  Getting Started, \emph{Circuit canvas}; Language Reference,
  \emph{Bounded child-process recursion} and \emph{Structured classical
  branches}.
  \item \textbf{Dashed lines labelled IC, S, or L:} cycle boundaries and
  checkpoints; Getting Started, \emph{Circuit canvas}.
  \item \textbf{Reset state, Clear circuit, or Reset site:} \emph{Reset: an
  operation that is not a gate}, in Getting Started, the Theory Guide, and the
  Language Reference.
\end{itemize}

\section{A safe first action}

Open the Circuit builder, load a starter circuit, choose \textbf{Play Sequence},
and observe each gate before writing source. Nothing is uploaded to a server for
simulation; the state-vector simulator runs in the browser.

When ready to edit text, use a listing explicitly marked
\textbf{Complete runnable protocol}. Instruction fragments are reference
material and may not compile by themselves.
